Transaction-level savings

Each expense can record an estimated cost and an actual cost. PaisaPilot calculates the difference for that individual transaction—no monthly budget is required.

Estimated cost − actual cost = transaction saving (minimum ₹0). Transfers between your own accounts never count as savings.

Older expenses without an estimate and legacy Saving Wins remain in history; they are not automatically credited. This prevents invented or duplicate savings.

Encrypted backup & restore

All records are stored in IndexedDB on this device. Backup files are encrypted with a password you choose using AES-GCM and PBKDF2. Your password is never stored or recoverable.

Keep the password safe. If you lose it, the backup cannot be decrypted. Restore replaces the current dataset after confirmation. There is no cloud sync or multi-device access.
